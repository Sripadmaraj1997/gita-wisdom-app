# Gita Wisdom Screenshot Checklist

Capture these screens for App Store Connect and Google Play internal testing:

- Splash screen with gold Gita Wisdom mark.
- Onboarding: Ancient Wisdom.
- Login screen.
- Home screen with Daily Verse and Owner Wisdom hidden for normal users.
- Chapters screen.
- Verse Reader screen with Sanskrit, transliteration, translation, save, and audio button.
- Ask Gita screen with verse card, Owner Wisdom section, and formatted answer.
- Journal screen with either an empty state or one sample entry.
- Saved Verses screen with either an empty state or one saved verse.
- Settings screen with Privacy Policy and Logout.

Recommended sizes:

- iPhone 6.7": 1290 x 2796.
- iPhone 6.5": 1242 x 2688.
- Android phone: 1080 x 1920 or higher.
- Android tablet if tablet support is enabled.
